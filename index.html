Function

          ② اضغط Create a new function

          ③ اكتب الاسم: sign-license ثم اضغط Create

          ④ احذف الكود الموجود والصق الكود أدناه بالكامل

          ⑤ اضغط Deploy
        

        

          

            sign-license / index.ts
            
          

          

        

        

          ⚠️ لا تضغط Deploy قبل الخطوة 5 — الـ Function تحتاج Secrets لتعمل.

5

        

          
إضافة Secrets — المفاتيح السرية

          
مخزّنة في Supabase — لا تظهر في الكود

        

        
Secrets

      

      

        

          ① في لوحة Supabase اضغط Edge Functions

          ② اضغط Manage Secrets (أو من القائمة الجانبية → Settings → Vault)

          ③ أضف هذين السرّين بالضبط:
        

        

          

            LICENSE_SECRET
            Mounir2026
            
          

          

            ADMIN_TOKEN
            STOC-ADMIN-CHANGE-ME-2026
            
          

        

        

          ⚠️ غيّر القيمتين إلى كلمات سر قوية من اختيارك — هذه مجرد قيم افتراضية.

          ADMIN_TOKEN يجب أن يطابق تماماً ما ستدخله في الإعدادات (الخطوة 6).
        

        

          🔗 فتح Manage Secrets
          
        

      

    


    
    

      

        
5b

        

          
إنشاء حساب المدير في Supabase Auth

          
الإيميل وكلمة السر اللي ستدخل بها للتطبيق

        

        
Auth

      

      

        

          ① في لوحة Supabase اضغط Authentication من القائمة الجانبية

          ② اضغط تبويب Users

          ③ اضغط Add user → Create new user

          ④ أدخل إيميل المدير وكلمة سر قوية

          ⑤ اضغط Create user
        

        

          ⚠️ احفظ الإيميل وكلمة السر — ستدخلهما في شاشة الدخول لـ STOC Manager.

          يمكنك تغيير كلمة السر لاحقاً من لوحة Authentication → Users.
        

        

          💡 يمكنك إنشاء أكثر من حساب مدير — كل واحد سيملك نفس الصلاحيات.
        

        

          🔗 فتح Authentication

إدخال الإعدادات واختبار الاتصال

          
الخطوة الأخيرة

        

        
اكتمال

      

      

        

          ① اضغط ✕ لإغلاق هذا الدليل

          ② في نافذة الإعدادات أدخل Project URL الذي نسخته في الخطوة 2

          ③ أدخل Admin Token — نفس قيمة ADMIN_TOKEN التي أضفتها في Secrets

          ④ اضغط 🔌 اختبار الاتصال — يجب أن تظهر رسالة "🟢 الاتصال ناجح"

          ⑤ اضغط 💾 حفظ وتطبيق
        

        

          💡 عند النجاح ستُعاد لوحة الشركات تلقائياً. إذا ظهر جدول stoc_licenses سيختفي البانر الأحمر أعلى الصفحة.
